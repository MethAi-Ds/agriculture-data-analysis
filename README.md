🌱 Agriculture Data Analysis

An exploratory data analysis project investigating global crop yield patterns and the relationship between agricultural productivity and environmental factors.

🎯 Project Objectives

- Analyse crop yield across countries, crops and years.
- Investigate rainfall, temperature and pesticide usage.
- Identify patterns and insights from agricultural data.
- Reconstruct the dataset after identifying unusual duplicate records.

🔍 Key Findings

- Potatoes recorded the highest average crop yield.
- Rainfall showed almost no linear correlation with crop yield.
- Pesticide usage showed a weak positive correlation.
- Temperature showed a weak negative correlation.
- Lower-temperature records had a higher proportion of extremely high yields in the threshold investigation.

Tools Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook
